# 통합 JSON 수집 v7

네이버 중계와 KBO 공식 중계·박스스코어를 합친 JSON을 한 번에 수집합니다. 기존 네이버 JSON/ZIP 및 공식 중계 추가 수집도 지원합니다.

## 실행 방법

1. 기존 프로그램을 종료하고 v7 ZIP을 새 폴더에 모두 압축 해제합니다.
2. `NaverSabermetrics.Desktop.exe`를 실행합니다.
3. 수집이 완료된 통합 JSON 파일 또는 해당 파일들이 들어 있는 ZIP을 선택해 DB 수집을 실행합니다.
4. 마지막 공식 기록정정·타점·팀 자책점 대조까지 기다립니다.
5. 작업 로그의 성공 경기 수와 `KBO 팀 자책점 ... 대조 완료` 또는 `적용 보류` 이유를 확인합니다.

기존 DB를 삭제할 필요는 없습니다. 다시 선택한 경기들은 새 수집 버전으로 재집계하며, 잘못된 파일이나 저장 실패가 발생한 경기는 기존 DB 기록을 보존합니다. 원본 네이버/통합 JSON과 ZIP은 이후 공식 정정 재처리에 사용하므로 유지해주세요.

통합 JSON을 일부 경기만 확보했다면 해당 경기부터 추가 수집해도 됩니다. 공식 박스스코어가 없는 경기까지 새 공식 개인 기록으로 바뀌지는 않습니다.

## 기록 적용 기준

| 항목 | 적용 자료 |
|---|---|
| 투구 위치·구속·투구 원자료 | 네이버 |
| 타석 결과 | KBO 공식 중계와 이후 공식 기록정정 |
| 개인 최종 타수·안타·홈런·볼넷·삼진·실점·자책점·이닝·타점 등 | 제공된 공식 박스스코어 필드 |
| 박스스코어에 없는 사구·고의사구·2루타·3루타·희생번트·희생플라이 등 | 중계로 계산한 기존 값 유지 |
| 공식 일자별 타점 | 같은 날짜·상대·기본 기록을 확인하고, 더 최신인 경우 적용. 더블헤더는 경기 구분이 안 되는 일자 자료로 덮지 않음 |
| 시즌 전체 팀 자책점·ERA | KBO 팀 투수 기록 페이지의 공식 팀 값 |

박스스코어의 `희타`를 임의로 희생번트나 희생플라이 한쪽에 넣지 않습니다. 공식 최종 수치와 타석 합계가 다르면 진단을 남기며, 특정 타석·투구를 임의로 만들어 합계를 맞추지 않습니다.

개인 자책점과 팀 자책점은 서로 분리합니다. 팀 자책점 차이를 개인이나 특정 경기의 자책점에 나눠 넣지 않습니다.

## 공식 팀 자책점 자동 대조

수집 작업이 끝나면 해당 시즌의 KBO 공식 팀 투수 기록을 한 번 조회합니다. 신규 파일이 없어 캐시를 사용하는 경우에도 최신 저장 시즌의 공식 대조를 실행합니다.

공식 페이지의 연도·정규시즌·팀 수를 확인하고, DB와 팀별 경기 수·이닝의 아웃 수·실점을 비교합니다. 모두 일치하는 경우에만 시즌 전체 팀 자책점·ERA에 적용합니다. 조회 후에는 원문, 조회 시각과 대조한 DB 경기 범위를 저장합니다.

월간·특정 기간·상대별·홈/원정·구장·상황별 조회에는 시즌 누적값을 적용하지 않습니다. DB에 경기가 추가되거나 대조 범위가 달라지면 과거 스냅샷도 적용하지 않습니다. 공식 페이지 갱신이 늦거나 일부 경기만 DB에 있다면 `적용 보류`가 정상입니다. 개인 기록과 WAR 계산에 팀 누적 자책점을 덮어쓰지 않습니다.

## 검증 범위와 배포

- 제공된 2026-09-11 네 경기의 공식 선수 기록 143행, 타석 314개, 투구 데이터 1,218개를 확인했습니다.
- 누락 필드 유지, 잘못된 입력 거부, 재수집 우선순위, 저장 실패 시 기존 경기 보존, 팀 기록의 기간·범위 제한을 임시 DB로 검증했습니다.
- 공식 페이지에서 내려받은 실제 HTML의 10팀 자책점 합계 5,706점을 확인했습니다.
- 자동 HTTP 응답 처리와 실패 처리는 검증용 응답으로 확인했습니다. Codex 실행 환경에서는 Windows TLS 자격 증명 제한으로 .NET의 실제 HTTPS 연결을 끝까지 확인하지 못했습니다. 일반 PC 실행에서의 실제 조회 결과는 작업 로그로 확인할 수 있습니다. TLS 인증서 검증을 완화하는 코드는 포함하지 않았습니다.

이 실행 파일은 로컬 수정본입니다. PC와 웹 서버의 관련 소스도 수정했지만 GitHub 반영 및 Render 배포는 별도입니다. 웹에서 새 팀 자책점 표시를 사용하려면 수정된 웹 코드와 공식 대조 결과가 포함된 DB를 함께 배포해야 합니다.

최종 검증: 통합 수집·팀 자책점 2,139개 체크와 기존 파서·추가 공식 중계·타점 61개 체크가 통과했습니다. PC Release 실행 파일과 WEB 서버 빌드가 성공했습니다.
