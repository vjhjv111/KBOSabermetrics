# 세이버매트릭스 Phase 1

추가 화면:

- 타자 세이버: BB%, K%, BB/K, ISO, BABIP, wOBA*, wRAA*, wRC*, wRC+*, OPS+
- 투수 세이버: IP, K%, BB%, K-BB%, BABIP, LOB%*, K/9, BB/9, HR/9, FIP*, FIP-*, xFIP*, xFIP-*
- 타자 선구·컨택: Swing%, Contact%, Whiff%, CSW%, Z-Swing%, O-Swing%, Z-Contact%, O-Contact%, SwStr%, 초구 Swing%, P/PA
- 투수 존·컨택: 동일 지표를 투수 기준으로 집계
- 리그 상수: 현재 시즌/경기 구분 필터에 사용된 리그 환경과 계산 상수

## 별표(*)의 의미

별표 항목은 Phase 1 잠정값입니다. 현재 원본에 자책점, 정확한 시즌별 선형가중치, 구장 보정 자료가 없으므로 다음 제한이 있습니다.

- wOBA 계열은 중앙화한 고정 선형가중치를 사용합니다.
- wRC+는 구장 보정 없이 현재 선택 데이터의 리그 R/PA를 기준으로 환산합니다.
- 투수 IP는 해당 투수가 기록한 타석 아웃 수 합계를 3으로 나눕니다.
- FIP 상수는 ERA 대신 타석 귀속 득점 기반 리그 RA9에 맞춥니다.
- LOB%는 타석 귀속 득점 기반 근사치입니다.
- xFIP의 FB는 문자 중계의 뜬공/팝업 분류를 이용합니다.

이 값들은 DB 단계에서 시즌별 상수 테이블, 자책점과 승계주자 책임, 구장 팩터를 추가하면 공식에 더 가깝게 교체할 수 있습니다.
