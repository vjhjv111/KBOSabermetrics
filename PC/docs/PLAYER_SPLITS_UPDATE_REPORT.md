# V2 선수 개인페이지 분석 확장 보고서

## 반영 기능

- 실제 기록 기준 역할 판정: 타격 기록이 없는 선수는 타격·Rolling·타자 구종 탭을 숨기고, 투구 기록이 없는 선수는 투구·투수 구종 탭을 숨깁니다. 겸업 선수는 양쪽을 모두 표시합니다.
- 상대별 분석: 타자는 상대 수비팀, 투수는 상대 공격팀을 기준으로 PA/AB/H/2B/3B/HR/BB/HBP/SO 및 AVG/OBP/SLG/OPS를 집계합니다.
- 상황별 분석: 주자 상태, 아웃카운트, 이닝 구간, 점수차, 득점권 여부, 클러치 여부를 제공합니다.
- 클러치 기본 정의: 7회 이후이면서 절대 점수차 3점 이내입니다.
- 타자 구종별 분석: 타석의 마지막 투구 구종에 타석 결과를 귀속해 AVG/OBP/SLG/OPS를 계산합니다.
- 투수 구종별 분석: 투구 수, 사용률, 평균 구속, 스트라이크%, Swing%, Whiff%, Contact%, CSW%를 표시합니다.
- 시즌 필터와 상황 종류 필터가 새 분석 탭에도 함께 적용됩니다.
- PlateAppearances 및 Pitches에 선수·상황·구종 조회용 인덱스를 보강했습니다.

## 데이터 구조 원칙

모든 새 분석은 관계형 `PlateAppearances`, `Pitches`, `Games` 테이블만 조회합니다. 원본 JSON이나 DB 내부 JSON 역직렬화 경로는 사용하지 않습니다. 새 분석 축이 추가되더라도 원시 관계형 테이블 위에 SQL/DTO를 확장하도록 구성했습니다.

## 현재 한계

- 상대별은 현재 팀 단위입니다. 상대 선수별 표는 타자는 상대 투수, 투수는 상대 타자로 추가 확장할 수 있습니다.
- 좌투/우투 분리는 원본 선수 프로필의 투타 정보가 모든 역사 데이터에서 안정적으로 보존되는지 추가 검증한 후 적용하는 것이 안전합니다.
- 구종별 타격은 `최종 투구 구종 기준`이며 화면과 공식 문서에 이를 명시했습니다.
- 실제 컴파일은 Windows의 Visual Studio 또는 `verify-v2.bat`로 최종 확인해야 합니다.
