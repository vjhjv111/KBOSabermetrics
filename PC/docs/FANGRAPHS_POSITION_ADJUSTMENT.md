# FanGraphs 포지션 보정 적용

## 보정값

1,458 수비이닝(162경기 × 9이닝) 기준:

- C: +12.5 Runs
- SS: +7.5 Runs
- 2B / 3B / CF: +2.5 Runs
- LF / RF: -7.5 Runs
- 1B: -12.5 Runs
- DH / PH: -17.5 Runs

## 계산식

```text
Position Runs = Σ(포지션별 수비이닝 / 1,458 × 포지션 보정값)
```

DH/PH는 수비이닝이 없으므로 현재 프로그램에서는 다음과 같이 계산합니다.

```text
DH/PH Position Runs = DH/PH PA / 600 × -17.5
```

## 데이터 제한과 추정

현재 네이버 릴레이 원본에는 모든 선수의 정확한 포지션별 수비이닝이 완전하게 제공되지 않습니다.
따라서 프로그램은 경기별 타격 라인을 이용해 다음과 같이 추정합니다.

- 선발 출전: 9.0 수비이닝
- 교체 출전: 4.5 수비이닝
- 한 경기에서 여러 수비 위치가 표시되면 추정 이닝을 균등 배분
- DH/PH는 해당 경기의 PA를 사용

GUI의 `타자 Value·WAR` 탭에서 `포지션 산정 근거`와 `추정 수비이닝`을 함께 표시합니다.
따라서 정확한 수비이닝 데이터가 추가되면 추정 로직을 실제 이닝 기반 로직으로 교체할 수 있습니다.
