# KBO 정규시즌 판정 기준

정규시즌 판정은 네이버 경기 정보의 `roundCode`가 대소문자를 무시하고 정확히 `kbo_r`인 경우로 한정합니다.

- `categoryId = kbo`만으로 정규시즌으로 판정하지 않음
- `categoryName` 또는 기타 이름에 `정규`가 포함됐다는 이유로 판정하지 않음
- GUI의 `정규시즌` 필터도 `roundCode == kbo_r`를 직접 검사
- 리그 상수는 읽어온 전체 데이터 중 `roundCode == kbo_r`인 경기 전체를 사용
- 연도, 팀, 포지션, 규정타석/이닝 화면 필터는 리그 상수 소스에 영향을 주지 않음
