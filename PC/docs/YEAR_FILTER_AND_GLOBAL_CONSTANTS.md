# 연도 필터와 전체 데이터 리그 상수

## 연도 필터

읽어온 경기의 `SeasonYear` 값을 기준으로 연도 목록을 자동 구성합니다.

- 전체 연도
- 2026
- 2025
- ...

연도 필터와 경기 구분 필터는 동시에 적용됩니다.

## 리그 상수 기준

화면에 표시되는 선수 기록은 선택한 연도 및 경기 구분만 사용합니다.
반면 wOBA 비교 기준, 리그 R/PA, RA9, FIP 상수, HR/FB 등 리그 환경은 프로그램이 읽어온 전체 경기에서 계산합니다.

예를 들어 2025년을 선택하더라도 리그 상수는 현재 로드된 2024~2026 전체 데이터에서 계산됩니다.
