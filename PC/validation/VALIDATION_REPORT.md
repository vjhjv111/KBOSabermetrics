## 5. 예상된 경고

`20260627HTOB02026`의 실제 투구 1개에는 연결 가능한 PTS 행이 없습니다. 파서는 작업을 중단하지 않고 `HasPtsTracking=false`와 `MISSING_PTS` 경고로 남기도록 설계되어 있습니다. 따라서 7경기 기준 정상 경고 수는 1건입니다.

## 6. 사용자 환경 최종 확인

Visual Studio에서 다음 순서로 확인합니다.

```text
NaverSabermetrics.sln 열기
→ NaverRelay.Gui를 시작 프로젝트로 설정
→ 솔루션 빌드
→ F5 실행
→ '7경기 샘플' 선택
→ '파싱 시작'
```

명령줄에서는 다음을 사용할 수 있습니다.

```powershell
build.bat
run-gui.bat
```

```text
7경기 기준 샘플 검증: PASS
```
