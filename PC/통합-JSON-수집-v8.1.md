# 통합 JSON 수집 v8.1

v8의 기록 처리 방식을 유지하면서, ‘파싱 시작’을 누른 뒤 첫 파일 처리 전의 준비 과정을 개선했습니다.

## 실행

1. 기존 프로그램을 종료합니다.
2. ZIP을 새 폴더에 모두 압축 해제하고 `NaverSabermetrics.Desktop.exe`를 실행합니다.
3. 다음 자료 수집부터 이 실행 파일을 사용합니다.

기존 DB를 그대로 사용합니다. v8에서 수집을 완료했다면 이번 업데이트 때문에 다시 수집할 필요는 없습니다. 캐시 버전도 v8로 유지하므로 변경되지 않은 v8 자료를 강제로 재파싱하지 않습니다.

## 변경 내용

- 버튼을 누르는 즉시 준비 상태와 경과시간을 표시하고 중복 실행을 막습니다.
- DB 준비와 캐시 비교를 화면 처리와 분리해 준비 중에도 화면과 취소 버튼이 반응합니다.
- 캐시 비교 중 파일명, 완료 개수, 본문 검사 개수, 캐시 일치 개수를 표시합니다.
- DB 준비 시간과 전체 준비 시간을 작업 로그에 남깁니다.
- 신규·구버전·미검증 자료는 본문을 미리 읽지 않고 파싱 대상으로 분류합니다.
- 현재 v8 캐시는 파일 전체 내용을 비교합니다. 크기나 수정시각이 그대로인 파일의 내용 변경도 감지합니다.

## 준비 시간

현재 자료는 종료 경기 622개, 약 3GB입니다. 별도 측정에서 전체 내용 비교에 약 16초가 걸렸으며, 저장 장치와 OneDrive 파일 상태에 따라 달라질 수 있습니다. 기존 v8 캐시를 확인할 때 이 검사는 계속 필요하지만, 이제 검사 진행 상황과 취소 기능을 사용할 수 있습니다.

## 이번 수집 로그 해석

사용자가 확인한 결과는 파싱 578경기와 캐시 44경기를 합친 종료 경기 622개 처리 완료, 파일 실패 0건입니다. 경기 전 자료 4개는 경기 종료 후 다시 수집하면 됩니다. 타점 확인 필요는 0건이며, 공식 팀 자책점 5,706점이 적용됐습니다.

공식 정정 대조에 남은 18경기는 야수 실책·투수 상대 타수 등 현재 정정 공지에서 자동 처리하지 않는 항목입니다. 파일 수집 실패와는 별개이며, 자세한 대상은 작업 로그의 정정 보류 내역을 확인할 수 있습니다.

PC와 웹 소스에 캐시 검사 개선을 반영했습니다. 이 ZIP은 로컬 실행용이며 웹 서버 배포는 별도입니다.
