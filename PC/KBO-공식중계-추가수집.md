# 공식 문자중계 추가 수집

1. 기존처럼 네이버 JSON을 선택해 SQLite DB에 수집합니다.
2. 파일 목록에서 KBO `*_playlog.json` 파일을 선택해 같은 수집 작업을 실행합니다. 여러 경기 파일을 함께 선택할 수 있습니다.
3. 프로그램이 파일 형식을 자동 판별해 해당 경기만 재집계합니다. 전체 DB를 삭제할 필요는 없습니다.

네이버 원본 파일 또는 ZIP은 원래 위치에 보관해주세요. 공식 파일을 추가할 때 기존 네이버 원본을 다시 읽어 선수 ID와 투구 데이터를 결합합니다. 원본을 옮겼으면 먼저 새 위치에서 네이버 파일을 다시 수집해주세요.

공식 JSON은 `gameId`, `order: chronological`, `count`, `logs: [{sequence, sourceId, text}]` 형식이며 마지막 문장은 `경기종료`여야 합니다. 네이버 파일과 공식 파일은 별도 단계로 수집해주세요.

## 반영 범위

- 공식 중계의 타석 결과를 우선하며, 이닝·공수·타순·선수·등장 순서로 대응합니다.
- 식별 가능한 누락 타석을 보완합니다. 타자 PA/AB/H/HR/BB/HBP/SO와 투수 H/HR/BB/HBP/SO 박스스코어를 타석 결과로 재집계합니다.
- 기존 공식 기록정정 대조는 그 다음에 적용합니다. 문자중계가 정정 전 내용일 수 있으므로 발표된 정정 내역도 계속 반영합니다.
- 네이버의 선수 정보, 기존 투구 좌표/구속/구종은 유지합니다. 추가한 타석의 투구·좌표·WPA는 만들어 넣지 않습니다.
- 주루·교체·득점·자책점·이닝·승패/홀드/세이브 전체를 공식 문자로 재구축하는 기능은 이번 반영 범위가 아닙니다. 해당 데이터는 기존 자료를 유지합니다. 타점은 아래의 공식 일자별 기록 검증으로 별도 보정합니다.
- 공식 중계 원문은 DB의 `OfficialPlayLogs`에 저장됩니다. 이후 네이버 JSON을 다시 읽거나 정정 대조가 재실행되어도 자동으로 다시 적용됩니다.
- 파일을 두 번 수집해도 중복 타석은 생기지 않습니다. 불완전 파일, 경기 ID 불일치, 동명이인 등 식별 불가, 타석 구성 불일치는 오류로 알리고 기존 경기와 공식 보정 내역을 보존합니다.

## v6: 타수·희생타·병살타와 공식 타점 대조

- 야수선택으로 출루, 병살타로 출루는 타수에 포함합니다. 타자가 살았는지 여부는 별도로 유지합니다.
- 희생플라이 실책, 희생번트 야수선택/실책은 타수에서 제외하고 희생타로 집계합니다.
- 병살 실책 출루와 명시된 3루수→2루수→1루수 땅볼 삼중살도 해당 GDP 기록을 반영합니다. 일반 뜬공·직선타의 복수 아웃을 임의로 GDP로 바꾸지 않습니다.
- 2022년 이후 수집 시즌은 기존 KBO 정정 대조가 끝난 뒤 선수별 공식 일자 기록을 조회해 RBI를 검증합니다. 선수 한 명당 일자별 페이지를 한 번 읽으므로 처음 전체 시즌을 수집할 때 시간이 추가로 걸립니다. 화면에 진행 인원이 표시됩니다.
- 모든 선택 파일이 캐시된 경우에도 DB의 최신 정규시즌 공식 정정/타점 대조를 실행합니다.
- 타점은 날짜·상대·선수 ID와 PA/AB/H/HR/BB/HBP/SO가 모두 맞을 때만 공식 값으로 보정합니다. 실책 득점이나 병살 득점을 기계적으로 RBI로 더하지 않습니다.
- 일자별 페이지로 경기 하나를 확정할 수 없는 더블헤더, 기본 기록 불일치, 원본 누락은 보류합니다. 사이트 형식 변경/조회 실패 역시 보류하며 기존 데이터는 유지됩니다. 연속 3회 조회 실패 시 남은 조회를 중단하고 로그에 남깁니다.
- 공식 근거는 `OfficialDailyBattingSources`, 반영/보류 내역은 `Diagnostics`의 `KBO_RBI_APPLIED`/`KBO_RBI_PENDING`으로 저장합니다. 원본을 재수집해도 검증된 공식 타점이 다시 적용됩니다.
- 이번 버전으로 처음 업데이트하면 2026년 네이버 JSON을 다시 선택하여 수집하세요. 캐시 버전을 올렸으므로 이전 판정을 재사용하지 않습니다. DB에 저장된 KBO 문자중계는 자동 재적용되므로 다시 선택할 필요가 없습니다.

2026년 622경기와 DB에서 추출한 공식 중계 572경기를 재계산해 10개 팀의 PA/AB/H/BB/SO/SH/SF/GDP가 공식 표와 일치함을 확인했습니다. 타점은 최지훈(5/14, 3→2)·손아섭(7/5, 0→1)의 공식 일자 기록 보정을 적용하면 팀별 합계도 일치합니다. 공식 HTTP 응답을 보관한 파일로 파싱·보정·재수집 유지·불일치 차단·조회 실패 처리를 테스트했습니다.
