# 통합 JSON 수집 v8

v7의 통합 JSON 수집에서 발생한 낫아웃·동명이인 연결 오류를 수정한 버전입니다.

## 실행

1. 기존 프로그램을 종료합니다.
2. v8 ZIP을 새 폴더에 모두 압축 해제하고 `NaverSabermetrics.Desktop.exe`를 실행합니다.
3. `NaverKboCombined` 폴더를 선택해 DB 수집을 다시 실행합니다.
4. 공식 정정·타점·팀 자책점 대조까지 기다립니다.

기존 DB는 그대로 사용하며 삭제할 필요가 없습니다. 이번 버전에서는 선택한 파일을 한 번 다시 계산합니다. 원본 JSON을 다시 다운로드할 필요는 없습니다. 개별 파일 수집이 실패하면 해당 경기의 기존 DB 기록을 보존합니다.

## 수정 내용

- 낫아웃 결과의 “다른주자 수비로 출루”를 주자 이동 문장으로 오인해 제외하던 문제를 수정했습니다. 삼진·타수·출루를 함께 기록합니다.
- 양 팀에 동명이인이 있으면 같은 선수 객체를 공유해 타순이 바뀌던 문제를 수정했습니다. 선수 코드와 팀을 분리해 관리합니다.
- 같은 팀 동명이인의 공식 선수 ID가 비어 있을 때, 전체 타순·교체·등판 순서와 확정 ID, 후보 목록, 개인 기록이 모두 맞아 유일하게 확인되는 경우에만 연결합니다. 구분할 수 없는 경우에는 수집을 보류합니다.
- 경기 전 상태가 명시된 빈 자료는 `경기 전 보류`로 표시합니다. 종료 경기의 자료 누락은 계속 파일 실패로 처리합니다.
- 파일 실패, 경기 전 보류, 공식 대조 확인 항목을 별도로 표시합니다. 정정·타점 보류에는 경기 ID와 상세 사유를 남깁니다.
- 수집 후 전체 작업 로그를 DB 폴더 아래 `Logs/import-날짜-시간.log`에 저장합니다. 저장 위치는 화면 로그에 표시합니다.
- 신규 자료가 모두 경기 전이거나 실패한 재시도에서도 기존 DB 최신 시즌의 공식 기록 대조를 실행합니다.

## 기록 적용

투구 위치·구속은 네이버 원자료를 유지하고, 타석 결과는 KBO 공식 중계를 따릅니다. 개인 최종 기록은 공식 박스스코어에 제공된 항목을 적용합니다. 제공되지 않은 항목은 중계 자료로 보완합니다.

팀 자책점은 공식 팀 투수 페이지와 경기 수·이닝·실점을 대조해 시즌 전체 팀 자책점과 ERA에 적용합니다. 개인 자책점에 팀 차이를 나눠 넣지 않습니다. 기간·상대·상황 등으로 필터링한 기록에는 시즌 전체 팀 자책점을 사용하지 않습니다.

이 파일은 로컬 실행용 수정본입니다. PC와 웹 소스는 함께 수정했으며, GitHub 반영·웹 서버 배포는 별도입니다.

## 전체 자료 검증 결과

- 기존 오류 26경기 복구 확인. 모든 경기의 공식 적용 전후 투구 이벤트가 동일함을 확인.

- GDP 910 / SH 517 / SF 383 / 2B 1,965 / 3B 174 / HBP 737 / IBB 125.
- 투수 개인 자책점 합계 5,736, 투구 이닝 아웃 수 33,081, 상대 타자 수 49,044.
- 최준용·원종혁·손주환·김진호·원종현의 해당 경기 실점·자책점이 공식 박스스코어와 일치.

공식 정정 공지의 야수 실책 등 현재 자동 반영 범위에 없는 항목은 `공식 대조 확인`에 남을 수 있습니다. 파일 저장 실패와 구분해 상세 사유를 작업 로그에서 확인할 수 있습니다. 과거 실행의 타점 보류 2건은 기존 합계 로그만으로 대상 선수를 특정할 수 없었으며, 이번 버전부터는 보류 시 경기·선수·비교 수치를 출력합니다.
