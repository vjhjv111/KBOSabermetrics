# Record Room UI Update

- 시작 화면을 시즌/통산/팀/상수 기록실로 재구성
- 시즌·통산·팀에서 타자/투수 2차 분류
- 타자 하위 탭 13개 적용
- 선수명 오른쪽 `적용 조건` 화면 열 추가
- 클러치·타구·타구방향·최종구 기준 구종 SQL 집계 추가
- 기존 데이터 적재·진단 화면은 `데이터 관리` 별도 창으로 유지
- 연봉 및 정밀 수비 등 원본이 지원하지 않는 항목 제외

## 투수 기록실 2.5 확장

투수 하위 탭도 화면 자료에 맞춰 다음 순서로 확장했습니다.

```text
기본 / 심화 / 가치 / 확장 / WP / 주자 / 선발 / 구원 / 타구 / 타구방향 / 투구 / 구종
```

세부 정의와 현재 원본 데이터에서 제외한 항목은 `docs/PITCHER_RECORD_ROOM.md`에 정리되어 있습니다.
