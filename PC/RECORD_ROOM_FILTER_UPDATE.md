# 기록실 상세 필터 업데이트

기록실 상세 필터에 다음 기능을 추가했습니다.

- 기간 직접 지정 / 최근 N일 / 최근 N경기
- 요일
- 홈/원정
- 상대팀(VS)
- 구장
- 선수명 검색
- 출력 개수: 50 / 100 / 200 / 500 / 전체
- 상세 옵션 조건 1 / 조건 2
  - 현재 선택한 기록 탭에서 숫자형 스탯이 자동 목록으로 표시됩니다.
  - 비교: 이상 / 초과 / 이하 / 미만 / 같음
  - 두 조건은 AND 조건으로 적용됩니다.
  - `%` 스탯은 `10` 입력 시 내부값 `0.10`으로 자동 변환합니다.

예시:
- 조건1: PA 200 이상
- 조건2: wRC+ 120 이상

필터 결과는 선수명 오른쪽의 `적용 조건` 열에도 표시됩니다.

## 구현 방식
상황/기간/상대/구장 등의 기존 필터는 SQLite 조회 조건으로 동작합니다.
조건1/조건2는 현재 조회 탭에서 생성된 숫자형 DTO에 적용되며 DB 재파싱이 필요하지 않습니다.
새로운 DB 컬럼이나 원본 JSON 재적재도 필요하지 않습니다.
