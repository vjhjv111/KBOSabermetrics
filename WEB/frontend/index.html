조회·계산 안내

집계, 정렬, 조건1·2 비교와 숫자 포맷은 서버에서 처리합니다. 화면에는 현재 페이지에 필요한 결과만 전달됩니다.

브라우저에 보이는 데이터의 수집을 완전히 차단할 수는 없습니다. IP 요청 제한, 일일 조회 한도와 결과 상한을 함께 적용합니다. 개발자 도구를 막거나 데이터를 숨기는 보안 방식은 사용하지 않습니다.

최근 N일은 DB의 마지막 경기일 기준입니다. 최근 N경기는 선택 팀 기준이며, 팀을 지정하지 않으면 리그 전체 최근 N경기입니다. 더블헤더는 별개 경기로 집계합니다.

상황 필터는 타석 시작 시점 기준입니다. 카운트 필터의 타격 성적은 해당 카운트에 도달한 타석, 투구 성적은 그 카운트에서 던진 공 기준입니다. 점수차는 공격팀 관점입니다.

리그 상수는 필터와 관계없이 적재된 모든 kbo_r 경기 기준입니다. 정확한 분리가 불가능한 상황별 최종 IP·ER·WAR 등의 지표는 표시하지 않습니다.

업로드된 KBO 투수 WAR v4 계산 구현을 서버에서 사용합니다. 웹의 투수 WAR는 KBO fWAR만 공개하며 RA9-WAR와 Blend WAR는 내부 계산용으로만 유지합니다. 사이트 추정치이며 공식 FanGraphs/Statiz 수치와 동일하다는 뜻은 아닙니다.
