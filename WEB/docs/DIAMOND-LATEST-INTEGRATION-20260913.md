## 소스와 통합 범위

- 입력 ZIP SHA-256: `651bc5be740ff1c4443cb2327538fa3c97e1fc71bf6f8692a8273ad80061fc82`
- 직전 ZIP SHA-256: `7613f9236df3f6ed2cc6520ec7f8747be0d73c68cb3d95584e4941cf738bfdf9`
- 직전 ZIP과 최신 ZIP 차이를 기존 웹 통합 코드에 병합했다. 기존 DB 로스터, 계정별 저장, 생성 한도, 탭 비활성화, 모바일 터치·스크롤 처리를 보존했다.
- 새 타이틀, 한국시간 기준 주야간 구장, 자동 다음 투구, 타격·투구 직접 플레이 선택, 수비 연출 후 결과 표시 및 최신 선수 모델·동작을 반영했다.

- 클라이언트와 서버의 투구 준비 시간을 함께 맞췄다. 실제 구속에 따른 비행시간 및 95ms 스윙 접촉 시점은 유지한다.

## 실제 검증

검증 서버는 `127.0.0.1:5118`, 게임 상태는 별도 QA 디렉터리를 사용했다. 선수 원본은 PC의 실제 `sabermetrics_v2.db`를 읽었다. 원본 DB와 운영 서버 게임 저장 자료는 수정하지 않았다.
