# 홈 경기 현황과 종료 즉시 순위

- 통계 DB의 편입 조건은 기존 그대로다. 날짜별 취소 경기 제외 전체 RESULT/ENDED 및 완성 JSON 확인 후 원자적으로 편입한다.
- 홈은 `RenderCollector:JsonDirectory`의 현재 시즌 최근 수집 구간 JSON을 읽는다. 점수·상태·이닝·현재 투수와 종료 투수 결정을 투영하고 파일 변경 시 캐시를 갱신한다. 전체 문자중계는 홈 캐시에 보관하지 않는다.
- 진행 중에는 `8회 초`처럼 이닝을 표시하고 양 팀 현재 투수를 P로 표시한다. 상세 링크는 숨긴다. RESULT/ENDED에서는 종료, 승패 투수, 상세 링크로 전환한다.
- 홈 순위·월간 순위·전망은 종료 JSON을 읽기 전용 연결의 임시 테이블에 더해 계산한다. 경기 ID로 중복을 제거하고 통계 DB에 편입된 공식 기록을 우선한다. 개인 기록/WAR 리더는 통계 DB만 사용한다.
- DB 편입 전 종료 상세는 JSON의 박스스코어·이닝 점수·결정 투수·문자중계·제공된 승리확률을 표시한다. 편입 후에는 기존 상세 경로가 사용된다. 정규화된 투구 위치는 DB 편입 후 제공된다.
- 홈을 보는 동안 60초마다 경기와 순위만 다시 조회한다. 숨겨진 탭에서는 조회하지 않고 개인 리더는 반복 계산하지 않는다. 갱신 실패 시 기존 화면을 유지하며 다음 주기에 재시도한다.
- 수집 일정에 STARTED 또는 PLAY가 있으면 수집 시작 기준 60초 후 다음 주기를 시작한다. 한 주기가 60초를 넘으면 완료 후 즉시 다음 주기로 넘어가며 수집 작업을 중첩하지 않는다. 진행 중에는 과거 시즌 backfill을 잠시 중단한다. 진행 경기가 없으면 기존 IntervalMinutes로 돌아간다.
- 화면은 수집 시각을 표시한다. 이는 수집 주기와 네트워크 지연을 포함하는 준실시간 현황이다. 별도의 외부 데이터 요청은 방문자별로 발생하지 않는다.

검증: `dotnet run --project WEB/validation/HomeLive/HomeLive.Validation.csproj`

진행 경기 순위 제외, 먼저 종료된 경기 반영, DB 무변경, 편입 후 중복 방지 및 DB 우선, JSON 캐시 갱신, 종료 전후 상세 접근, 1분 수집 간격과 기존 전체 종료 게이트를 검증한다.
