# 선수 모델과 동작 개선 — 2026-09-12

브라우저의 공용 3D 타자·투수 모델을 개선했다. 실존 선수의 얼굴을 스캔한 모델은 아니며, 기존 DB 선수 선택·팀 유니폼·투구손·타격 방향·투수 신장 연동을 유지한다.

## 형상과 재질

- 팔 위아래를 하나의 스킨 메시로 연결하고 어깨·팔꿈치 관절에 가중치를 부여했다. 근육 윤곽과 피부 음영을 더했다.
- 바지 앞면의 수평 접합부를 제거하고 앞면부터 가랑이와 뒷면까지 연속 곡면으로 연결했다. 한 차례 곡면 세분화로 굽힌 자세의 각진 부분을 완화했다.
- 얼굴의 눈꺼풀·코·입·볼 윤곽, 관자놀이를 따라가는 머리카락을 수정했다. 헬멧 이마 개구부를 올리고 통풍구를 표면에 붙였으며 UV 경계의 조명 이음새를 없앴다.
- 유니폼의 흉곽·주름·옆 봉제선·등판 절개선·칼라, 신발 혀·끈·밑창, 타자 팔꿈치·정강이 보호대를 보강했다. 배트는 손잡이와 타격 위치를 유지하면서 과하게 굵던 배럴을 줄였다.
- 옷감의 거친 표면과 은은한 광택, 피부·헬멧 반사를 조정했다. 카메라 방향에 맞춰 보조광을 배치하고 그림자 해상도를 늘리는 대신 유효 범위를 줄였다.

## 동작

- 투수의 준비·다리 들기·스트라이드·릴리스·팔로스루·복귀를 연속 보간한다. 골반이 먼저 돌고 글러브를 회수하며, 사이드암 궤도도 팔 길이 안으로 조정했다.
- 양다리에 역기구학을 적용하고 발목 회전을 분리했다. 타자의 앞발 지지와 뒷발 뒤꿈치 회전, 투수의 착지와 발 회수가 가능하다.
- 타격 접촉은 기존 95ms, 배트 손잡이/스위트스폿 경로 및 공의 릴리스 좌표를 유지한다. 서버 판정·실측 구종 및 코스 추출 로직은 변경하지 않았다.

## 검증

- TypeScript 검사, 게임 전체 테스트, 번들 빌드, .NET Release publish 통과.
- 좌우타·좌우투·사이드암의 손목 연결, 릴리스, 정상 스트라이크존 타격과 발 지지 검증 통과. 정상 존의 손목·지지점 오차는 테스트 출력 기준 0.000cm이다.
- 111개 동작 프레임에서 유한한 스킨 좌표를 검증했다. 팔과 바지의 가중치 합, 원형 보존, 실제 관절 변형, 스켈레톤·GPU bone texture·표면 맵의 해제를 확인했다.
- 타자 70개 메시/37,384삼각형, 투수 71개 메시/39,744삼각형으로 기존 모델당 50,000삼각형 한도 안이다. 형상 세분화·텍스처 생성은 초기화 시에만 수행한다.
- 같은 카메라의 개선 전/후 근접 화면에서 정면·후면·얼굴·좌우 타격·좌우 투구를 비교했다.
- 실제 DB 미리보기에서 1440px/390px 타자·투수 화면을 확인했다. 브라우저 오류, WebGL 대체 화면, 문서 가로 넘침 없음.
- Chrome 터치 에뮬레이션에서 경기 전/중 세로 스와이프가 스윙·투구를 잘못 발생시키지 않고, 이후 탭 스윙과 투구 버튼 요청이 성공했다. 실제 iPhone Safari 기기에서의 프레임률 검증은 하지 않았다.

생성된 게임 번들은 frontend와 서버 wwwroot에 함께 반영한다. 통계 DB 파일과 원본 JSON은 수정하지 않는다.
