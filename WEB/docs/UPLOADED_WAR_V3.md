# KBO 투수 WAR v4

## 목적

기존 투수 WAR는 FanGraphs형 ifFIP 구조를 사용했지만, 선발 0.12승/9이닝·구원 0.03승/9이닝의 고정 대체수준과 리그 전체 재중앙화 부재로 인해 KBO 데이터에서 투수 WAR 총량이 지나치게 낮아질 수 있었습니다.

v3는 다음 세 가지를 추가합니다.

1. KBO 최근 3개 정규시즌 표본으로 역할별 대체선수 성적 추정
2. 리그 목표 투수 WAR에 맞추는 KBO WARIP
3. 실제 실점 기반 KBO RA9-WAR와 70/30 Blend WAR

모든 리그 환경 계산은 `RoundCode == "kbo_r"` 경기만 사용합니다.

---

## 1. ifFIP와 pFIPR9

```text
ifFIP = [13×HR + 3×(BB+HBP) - 2×(SO+IFFB)] / IP + ifFIP 상수
FIPR9 = ifFIP + (리그 RA9 - 리그 ERA)
pFIPR9 = FIPR9 / (FIP PF / 100)
```

IFFB는 프로젝트에서 합의한 다음 결과를 포함합니다.

```text
포수 파울플라이
1루수 파울플라이
2루수 뜬공
3루수 뜬공
유격수 뜬공
투수 뜬공
```

## 2. 동적 Runs Per Win

```text
dRPW = ((((18 - IP/G) × 리그 FIPR9 + (IP/G) × pFIPR9) / 18) + 2) × 1.5
```

## 3. KBO 역할별 대체선수 수준

최근 3개 정규시즌에서 선발·구원을 분리한 저사용 투수 역할 라인을 표본으로 사용합니다.

```text
선발 후보: 최소 9IP, 역할 이닝 하위 40% 우선, 최대 50IP
구원 후보: 최소 5IP, 역할 이닝 하위 40% 우선, 최대 30IP
```

관측 성적은 소표본 영향을 줄이기 위해 리그 평균으로 회귀합니다.

```text
회귀 성적 = 리그 평균 + 신뢰도 × (관측 성적 - 리그 평균)
신뢰도 = IP / (IP + 회귀이닝)

선발 pFIPR9 회귀이닝 = 40
구원 pFIPR9 회귀이닝 = 20
선발 pRA9 회귀이닝 = 50
구원 pRA9 회귀이닝 = 25
```

우연한 소표본 호투 때문에 대체선수 수준이 지나치게 높아지는 것을 막기 위해, 기존 0.12/0.03 승 기준을 run-rate로 환산한 값을 최소 격차로 사용합니다.

```text
KBO 선발 Repl FIP- = 100 × 선발 대체 pFIPR9 / 리그 FIPR9
KBO 구원 Repl FIP- = 100 × 구원 대체 pFIPR9 / 리그 FIPR9
```

## 4. 보정 전 KBO fWAR

```text
RAA 승 = (리그 FIPR9 - pFIPR9) / dRPW × IP / 9
대체 승 = (대체 pFIPR9 - 리그 FIPR9) / dRPW × IP / 9
구원 LI 배수 = (1 + gmLI) / 2

보정 전 fWAR = RAA 승 + 대체 승
```

선발과 구원 역할은 별도로 계산하고, 구원 부분에만 LI 배수를 적용합니다.

## 5. KBO WARIP

```text
리그 전체 WAR 목표
= 리그 경기 수 × 2 × (0.500 - 대체선수 승률) × 투수 WAR 배분율

기본 정책:
대체선수 승률 = 0.294
투수 WAR 배분율 = 0.43
```

```text
KBO WARIP
= (목표 투수 WAR - 보정 전 리그 투수 WAR 합) / 리그 전체 IP

선수 WARIP 보정 = KBO WARIP × 선수 IP
최종 KBO fWAR v4 = 보정 전 fWAR + 선수 WARIP 보정
```

이 보정은 리그 전체 WAR 총량을 맞추면서 모든 투수에게 이닝에 비례해 동일한 보정률을 적용합니다.

## 6. KBO RA9-WAR

```text
RA9 = R × 9 / IP
pRA9 = RA9 / (구장 팩터 / 100)
RA9 dRPW = ((((18 - IP/G) × 리그 RA9 + (IP/G) × pRA9) / 18) + 2) × 1.5
```

이후 역할별 KBO 대체 RA9, 구원 LI 배수, RA9 WARIP를 같은 구조로 적용합니다.

현재 별도 득점 파크 팩터와 팀 수비·상대 타선 조정이 없기 때문에, pRA9에는 FIP PF를 대용값으로 사용합니다. 따라서 이 값은 공식 FanGraphs RA9-WAR와 동일하지 않은 사이트 보조 지표입니다.

## 7. Blend WAR

```text
Blend WAR = 0.70 × KBO fWAR + 0.30 × KBO RA9-WAR
```

수비 독립 성과를 주값으로 유지하면서 실제 실점 억제를 일부 반영하는 사이트 보조 지표입니다.

## 8. 화면과 공식표

다음 화면에 값이 노출됩니다.

- 투수 기본 기록실: KBO fWAR, KBO RA9-WAR, Blend WAR
- 투수 가치 기록실: 대체 FIP-, 보정 전 WAR, WARIP, 보정값, 최종 WAR
- 선수 개인페이지 연도별 투구 및 Value·WAR
- 팀 기록실 투구 및 Value·WAR
- 연도별 상수: 목표 WAR, 달성률, 역할별 대체수준, WARIP, 표본 수
- 공식·계산기 탭: 계산 단계와 제한 사항

## 9. 해석 주의

- KBO 대체선수 풀 정의는 사이트 정책이며 공식 KBO 지표가 아닙니다.
- RA9-WAR는 현재 팀 수비·상대 타선 조정이 없습니다.
- Blend WAR 70/30은 사이트 자체 보조 지표입니다.
- 소수점 한 자리 차이보다 구간과 역할별 비교를 중심으로 해석하는 것이 안전합니다.
