# 비교실·구속 대응력

2026-09-12 공개 페이지와 현재 SQLite 스키마를 확인해 추가한 기능입니다. 화면 구성의 아이디어를 참고했으며, 외부 사이트의 선수 통계나 자체 평가식을 복사하지 않습니다. 집계 원본은 이 프로젝트에 적재된 경기 DB입니다.

## 타자 비교실 (`#comparison`)

시즌과 최소 타석(기본 100 PA)을 선택합니다. 해당 시즌 정규시즌의 선수별 최종 경기 기록을 합산합니다. 선수 ID가 확정된 타자만 대상이며 올스타·시범·포스트시즌은 제외합니다. 팀 필터는 화면에 보이는 선수만 좁힙니다. 백분위의 기준 집단은 계속 전체 팀의 최소 타석 충족 선수입니다.

- 산점도: 출루율×장타율, 타율×순수장타율, 볼넷%×삼진%.
- 비교 카드: 최대 4명의 사진·원래 성적·백분위. 사진이 없는 경우 기본 표시.
- 유사 유형: 지정 선수와 기록 유형이 비슷한 다른 타자 최대 10명. 비교 추가와 개인 페이지 이동.

비율은 경기별 비율의 평균이 아니라 합산한 분자/분모로 계산합니다.

| 지표 | 계산 |
|---|---|
| AVG | H / AB |
| OBP | (H + BB + HBP) / (AB + BB + HBP + SF) |
| SLG | TB / AB |
| OPS / ISO | OBP + SLG / SLG − AVG |
| BB% / K% | BB / PA × 100 / SO / PA × 100 |

고의4구는 BB에 한 번만 포함합니다. 분모가 0이면 값은 `null`이며 화면에는 `—`가 나옵니다.

백분위는 같은 지표를 가진 유효 선수 N명에서 `100 × (낮은 값의 인원 + 같은 값의 인원/2) / N`입니다. 삼진%는 방향을 뒤집어 높은 백분위가 낮은 삼진율을 뜻합니다. 동률은 같은 중간 순위를 받으며, 혼자만 유효하면 50입니다. PA 백분위는 출장 표본의 크기이며 능력 점수가 아닙니다.

유형 거리는 AVG·ISO·BB%·K% 네 지표의 백분위 차이를 제곱해 평균한 뒤 제곱근을 취합니다. 네 지표의 가중치는 같고 범위는 0~100, 작을수록 비슷합니다. 본인은 제외하고 동률은 선수 ID로 정렬합니다. 네 지표가 모두 유효한 선수끼리만 계산합니다. 유사할 확률이나 미래 성적의 예측값이 아닙니다.

서버는 읽기 전용 연결, 요청 취소·시간 제한, 선수 최대 500명 제한을 적용합니다. `/api/comparison`은 한 번에 500행의 조회 예산을 예약합니다. 일반 기록실의 페이지 상한은 바꾸지 않습니다. 개별 타석·투구 원본이나 DB 파일은 응답하지 않습니다.

## 구속 대응력 (`#analysis=velocity`)

타자 또는 투수를 선택하고 시즌·날짜·팀·구종·타자 좌우·투구 전 카운트 조건을 적용합니다. 유효 구속은 40~180 km/h이며 다음 네 구간으로 나눕니다.

1. 120 km/h 미만
2. 120 이상 135 km/h 미만
3. 135 이상 150 km/h 미만
4. 150 km/h 이상

스윙률의 분모는 구간 내 투구 수, 헛스윙률의 분모는 구간 내 스윙 수입니다. 타격 성적은 **전체 타석에서 먼저 확인한 실제 마지막 투구**의 구속과 조건에 연결합니다. 예를 들어 마지막 공이 슬라이더인 타석은 포심만 필터했을 때 포심 종료 타석으로 바뀌지 않습니다.

공식 완료 타석 중 결과가 인식된 타석으로 AVG·OBP·SLG·OPS를 계산합니다. 투수 모드의 값은 마지막 투구를 던진 투수 기준의 상대 타격 성적이며, 교체 시 공식 투수 책임 성적과 다를 수 있습니다. 구속 누락·범위 밖·미분류 결과·무투구 타석은 커버리지에서 별도로 확인합니다. 무투구 타석은 구종·카운트 필터에 해당한다고 판정하지 않습니다.

작은 표본의 비율은 크게 변할 수 있으므로 투구 수, 종료 PA, AB와 분모를 함께 봅니다. 타구 속도나 발사각은 생성하지 않습니다.
